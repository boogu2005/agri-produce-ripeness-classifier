# 测试集 (test_dataset)

## 用途
最终评估模型性能的数据集，反映模型在真实环境中的表现。

## 目录结构
```
test_dataset/
├── 未熟/       # 未成熟农产品图片
├── 半熟/       # 半成熟农产品图片
└── 熟透/       # 熟透农产品图片
```

## 图片要求
- **格式**: JPG、JPEG、PNG、BMP
- **数量**: 约占总数据量的 **15%**
- **质量**: 与训练集保持一致的风格和标准
- **独立性**: 必须与训练集、验证集图片完全不同

## 比例建议
测试集占总数据量的 **15%**

## 使用场景
1. **最终评估**: 训练完成后评估模型准确率
2. **性能报告**: 生成最终模型的性能指标
3. **对比基准**: 与其他模型或方案对比

## 注意事项
- 测试集图片不能出现在训练集或验证集中
- 测试集评估结果是最可靠的模型性能指标
- 测试集应该代表真实世界的分布

---

## 数据集划分总结

| 数据集 | 用途 | 比例 | 在训练中的作用 |
|--------|------|------|----------------|
| train_dataset | 模型学习 | 70% | 拟合模型参数 |
| val_dataset | 超参数调优 | 15% | 调整模型配置 |
| test_dataset | 最终评估 | 15% | 评估真实性能 |
