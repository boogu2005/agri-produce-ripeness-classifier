# 验证集 (val_dataset)

## 用途
在训练过程中评估模型性能，用于调整超参数和监控模型泛化能力。

## 目录结构
```
val_dataset/
├── 未熟/       # 未成熟农产品图片
├── 半熟/       # 半成熟农产品图片
└── 熟透/       # 熟透农产品图片
```

## 图片要求
- **格式**: JPG、JPEG、PNG、BMP
- **数量**: 约占总数据量的 **15%**
- **质量**: 与训练集保持一致的风格和标准
- **独立性**: 必须与训练集图片完全不同（不能重复）

## 比例建议
验证集占总数据量的 **15%**

## 使用场景
1. **训练中验证**: 每个 epoch 结束后评估模型
2. **超参数调优**: 调整学习率、批次大小等参数
3. **早停策略**: 当验证集性能不再提升时停止训练
4. **模型选择**: 比较不同模型的验证集表现

## 注意事项
- 验证集图片不能出现在训练集中
- 验证集用于反映模型在真实场景下的表现
- 验证集表现好不代表测试集一定好
