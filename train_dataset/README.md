# 训练集 (train_dataset)

## 用途
训练模型使用的数据集，模型从中学习特征和模式。

## 目录结构
```
train_dataset/
├── 未熟/       # 未成熟农产品图片
├── 半熟/       # 半成熟农产品图片
└── 熟透/       # 熟透农产品图片
```

## 图片要求
- **格式**: JPG、JPEG、PNG、BMP
- **数量**: 越多越好（建议每类 200+ 张）
- **质量**: 清晰、光照均匀、果实区域占图片主体
- **多样性**: 不同角度、不同背景、不同成熟度梯度的图片

## 比例建议
训练集占总数据量的 **70%**

## 示例
假设总共 1000 张图片：
- 训练集: 700 张 (70%)
- 验证集: 150 张 (15%)
- 测试集: 150 张 (15%)

## 注意事项
- 图片文件名可以任意，不影响训练
- 子文件夹名称必须与代码中的 CLASSES 配置一致
- 避免图片损坏或无法读取
